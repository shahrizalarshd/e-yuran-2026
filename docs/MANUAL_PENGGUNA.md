## 1. PENGENALAN

### 1.1 Apa itu e-Yuran PPTT?

e-Yuran PPTT adalah sistem kutipan yuran dalam talian untuk ahli Persatuan Penduduk Taman Tropika Kajang. Sistem ini membolehkan anda:

- ✅ Melihat bil yuran tahunan rumah anda
- ✅ Membuat pembayaran secara dalam talian (ToyyibPay)
- ✅ Menyemak sejarah pembayaran
- ✅ Menerima notifikasi bil dan peringatan

### 1.2 Jenis Yuran

| Jenis Yuran | Keterangan | Kekerapan |
|-------------|------------|-----------|
| **Yuran Keahlian** | Bayaran untuk menjadi ahli PPTT | Sekali sahaja |
| **Yuran Tahunan** | Yuran penyelenggaraan taman | Setiap tahun |

### 1.3 Keperluan Sistem

- Pelayar web moden (Chrome, Safari, Firefox, Edge)
- Sambungan internet
- Telefon bimbit atau komputer

## 2. CARA LOGIN

### 2.1 Langkah Login

1. Buka pelayar web dan layari: **https://eyuran.pptt.my**

2. Pada halaman utama, klik butang **"Log Masuk"**

3. Masukkan maklumat login:
   - **E-mel**: E-mel yang didaftarkan
   - **Kata Laluan**: Kata laluan anda

4. Klik butang **"Log Masuk"**

### 2.2 Terlupa Kata Laluan?

1. Klik pautan **"Lupa Kata Laluan?"** pada halaman login
2. Masukkan alamat e-mel anda
3. Semak e-mel untuk pautan reset kata laluan
4. Klik pautan dan tetapkan kata laluan baru

### 2.3 Pendaftaran Akaun Baru

Jika anda belum mempunyai akaun:

1. Klik **"Daftar Akaun Baru"** pada halaman utama
2. Isi maklumat peribadi:
   - Nama penuh
   - Alamat e-mel
   - Nombor telefon
   - Kata laluan
3. Pilih **rumah anda** dari senarai
4. Pilih **hubungan** anda dengan rumah:
   - Owner (Pemilik)
   - Spouse (Pasangan)
   - Child (Anak)
   - Family (Keluarga)
   - Tenant (Penyewa)
5. Hantar pendaftaran
6. **Tunggu pengesahan** dari pentadbir PPTT
7. Anda akan menerima e-mel apabila akaun diluluskan

## 4. MELIHAT BIL

### 4.1 Senarai Bil

1. Dari menu, klik **"Bil Saya"**
2. Anda boleh menapis bil mengikut:
   - Status (Semua / Dibayar / Belum Dibayar)
   - Tahun

### 4.2 Butiran Bil

Setiap bil mengandungi maklumat:

| Maklumat | Keterangan |
|----------|------------|
| Tempoh Bil | Bulan dan tahun bil |
| Jumlah | Amaun bil (contoh: RM20.00) |
| Tarikh Akhir | Tarikh akhir pembayaran |
| Status | Dibayar / Belum Dibayar / Tertunggak |

### 4.3 Status Bil

| Status | Warna | Maksud |
|--------|-------|--------|
| **Dibayar** | 🟢 Hijau | Bil telah dijelaskan sepenuhnya |
| **Belum Dibayar** | 🔴 Merah | Bil belum dibayar |
| **Tertunggak** | 🟠 Oren | Bil melepasi tarikh akhir |
| **Separa** | 🟡 Kuning | Sebahagian dibayar |

## 5. MEMBUAT PEMBAYARAN

### 5.1 Jenis Pembayaran

Anda boleh memilih 3 jenis pembayaran:

| Jenis | Keterangan |
|-------|------------|
| **Bulan Semasa** | Bayar bil bulan ini sahaja |
| **Pilih Bulan** | Pilih bil tertentu untuk dibayar |
| **Setahun** | Bayar semua bil tahun semasa |

### 5.2 Langkah Pembayaran

#### Langkah 1: Pilih Bil

1. Dari Dashboard, klik **"Bayar Sekarang"** atau
2. Pergi ke menu **"Buat Pembayaran"**
3. Pilih jenis pembayaran:
   - **Bulan Semasa**: Sistem akan pilih bil bulan ini
   - **Pilih Bulan**: Tandakan bil yang ingin dibayar
   - **Setahun**: Sistem akan pilih semua bil tahun ini

4. Semak jumlah pembayaran
5. Klik **"Teruskan ke Pembayaran"**

#### Langkah 2: Pengesahan

Pada halaman pengesahan:

```
┌─────────────────────────────────────────┐
│  📋 RINGKASAN PEMBAYARAN                │
│                                         │
│  Bil yang akan dibayar:                 │
│  • Januari 2025 - RM20.00              │
│  • Februari 2025 - RM20.00             │
│                                         │
│  ─────────────────────────────────      │
│  JUMLAH: RM40.00                        │
│                                         │
│  [ ✅ SAHKAN & BAYAR ]                  │
└─────────────────────────────────────────┘
```

1. Semak senarai bil yang dipilih
2. Pastikan jumlah adalah betul
3. Klik **"Sahkan & Bayar"**

#### Langkah 3: Pembayaran ToyyibPay

1. Anda akan dialihkan ke **ToyyibPay**
2. Pilih kaedah pembayaran:
   - FPX (Online Banking)
   - Kad Kredit/Debit
3. Ikut arahan untuk melengkapkan pembayaran
4. **PENTING**: Jangan tutup pelayar semasa transaksi

#### Langkah 4: Resit Pembayaran

Selepas pembayaran berjaya:
1. Anda akan dikembalikan ke e-Yuran
2. Resit pembayaran akan dipaparkan
3. E-mel pengesahan akan dihantar

### 5.3 Status Pembayaran

| Status | Maksud |
|--------|--------|
| **Berjaya** | Pembayaran telah diterima |
| **Gagal** | Pembayaran tidak berjaya, cuba lagi |
| **Dalam Proses** | Menunggu pengesahan bank |

## 6. SEJARAH PEMBAYARAN

### 6.1 Melihat Sejarah

1. Dari menu, klik **"Sejarah Pembayaran"**
2. Senarai semua pembayaran akan dipaparkan

### 6.2 Butiran Pembayaran

Klik pada mana-mana pembayaran untuk melihat:

| Maklumat | Keterangan |
|----------|------------|
| No. Pembayaran | Nombor rujukan unik |
| Tarikh & Masa | Bila pembayaran dibuat |
| Jumlah | Amaun yang dibayar |
| Kaedah | FPX / Kad Kredit |
| Status | Berjaya / Gagal |
| Bil yang Dibayar | Senarai bil yang dilunaskan |

### 6.3 Muat Turun Resit

1. Buka butiran pembayaran
2. Klik butang **"Muat Turun Resit"** (jika tersedia)
3. Resit PDF akan dimuat turun

## 7. TETAPAN RUMAH

### 7.1 Maklumat Rumah

Memaparkan:
- Nombor rumah dan alamat
- Status keahlian PPTT
- Ahli rumah yang berdaftar

### 7.2 Tetapkan Pembayar (Owner sahaja)

Jika anda adalah **pemilik rumah**, anda boleh:

1. Pergi ke **"Tetapan Rumah"**
2. Lihat senarai ahli rumah
3. Pilih siapa yang boleh membuat pembayaran
4. Klik **"Simpan Tetapan"**

**Nota**: Hanya seorang sahaja boleh ditetapkan sebagai pembayar pada satu masa.

## 8. PROFIL PENGGUNA

### 8.1 Kemaskini Profil

1. Klik nama anda di bahagian atas
2. Pilih **"Profil"**
3. Kemaskini maklumat:
   - Nama
   - E-mel
   - Nombor telefon
4. Klik **"Simpan"**

### 8.2 Tukar Kata Laluan

1. Dari halaman Profil
2. Klik **"Tukar Kata Laluan"**
3. Masukkan:
   - Kata laluan semasa
   - Kata laluan baru
   - Sahkan kata laluan baru
4. Klik **"Kemaskini"**

### 8.3 Pilihan Bahasa

1. Klik ikon bahasa di bahagian atas
2. Pilih **Bahasa Malaysia** atau **English**
3. Antara muka akan bertukar kepada bahasa pilihan

## 9. SOALAN LAZIM (FAQ)

### Q1: Bagaimana jika pembayaran saya gagal?

**Jawapan**: Jika pembayaran gagal:
1. Semak baki akaun bank anda
2. Pastikan had transaksi mencukupi
3. Cuba lagi dengan kaedah pembayaran lain
4. Hubungi bendahari jika masalah berterusan

### Q2: Berapa lama untuk pembayaran dikemaskini?

**Jawapan**: Pembayaran melalui FPX biasanya dikemaskini dalam masa **5-10 minit**. Jika masih belum dikemaskini selepas 1 jam, sila hubungi bendahari.

### Q3: Bolehkah saya bayar untuk rumah lain?

**Jawapan**: Tidak. Anda hanya boleh membayar bil untuk rumah yang dikaitkan dengan akaun anda.

### Q4: Bagaimana jika saya berpindah rumah?

**Jawapan**: Hubungi Super Admin PPTT untuk:
1. Menutup akaun rumah lama
2. Mendaftarkan akaun rumah baru

### Q5: Adakah saya akan menerima peringatan bil?

**Jawapan**: Ya, sistem akan menghantar:
- Peringatan bil sebelum tarikh akhir
- Notifikasi bil tertunggak
- Pengesahan pembayaran

### Q6: Bagaimana jika saya tidak menerima e-mel pengesahan?

**Jawapan**: 
1. Semak folder Spam/Junk
2. Pastikan e-mel betul dalam profil
3. Hubungi bendahari untuk bantuan

### Q7: Apakah yuran yang perlu saya bayar?

**Jawapan**:
- **Yuran Keahlian**: RM20 (sekali sahaja untuk ahli baru)
- **Yuran Tahunan**: RM120/tahun (RM10/bulan)

*Nota: Amaun mungkin berubah mengikut keputusan AGM*

### Q8: Bolehkah saya bayar separuh daripada bil?

**Jawapan**: Ya, anda boleh memilih bil tertentu untuk dibayar. Pembayaran separa untuk satu bil tidak dibenarkan.
